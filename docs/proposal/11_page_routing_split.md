# Step 11. 기능을 페이지로 나누기

> 목적: Step 10에서 모은 **기능을 화면(페이지) 단위로 나눠** 배치한다.

> **Guide:**
>
> 1. Agent가 `docs/proposal/10_feature_list.md`의 기능 목록을 읽고 **페이지 구성 초안**을 작성한다.
> 2. 각 페이지에 **어떤 기능(F-xx)** 이 들어가는지 나열한다.
> 3. 팀이 페이지 수·이름·구성을 보며 수정한다.
>
> - Step 10의 기능은 **어느 페이지에든 모두 배치**한다. (이 단계에서 기능을 빼지 않는다)
> - 사용자 흐름이 자연스럽게 이어지도록 페이지를 묶는다. (예: 로그인 → 메인 → 상세)
> - 한 페이지에 기능이 너무 많으면 **페이지를 나눈다.**
> - **우선순위·스펙 아웃(이번에 만들지 않을 기능)** 은 Step 14 `docs/proposal/14_priority_matrix.md`에서 정한다.

**프롬프트 예시**

```
docs/proposal/10_feature_list.md와 docs/proposal/04~09 맥락을 읽고 docs/proposal/11_page_routing_split.md를 채워줘.

규칙:
- Step 10의 모든 기능(F-xx)을 어느 페이지에든 배치 (누락 없음)
- 페이지마다 이름·경로·목적·포함 기능 목록을 작성
- 기능 ID(F-xx)와 기능명을 함께 적기
- 해커톤 MVP 기준으로 페이지 수는 과하지 않게 (보통 3~6개)
- "페이지 간 이동 흐름" 섹션도 채우기
- 구조와 상단 Guide는 유지
```

## 페이지 1: 메인 페이지

> **경로:** `/`
> **목적:** 중앙의 뉴스/아티클 링크 입력창으로 분석을 시작하거나, 아래의 뉴스 리스트·섹터·증시 현황을 탐색해 진입하는 시작 화면.

- **F-01** 뉴스/아티클 링크 직접 입력 (단일·다중)
- **F-02** 링크(URL) 기반 입력 분석 (제출 시 분석 시작)
- **F-28** 메인 화면 구성 — 상단 아티클 링크 입력창, 그 아래 인기 뉴스·주요 섹터 현황(섹터별 등락률)·최근 분석 내역 섹션
- **F-20** 크롬 익스텐션 (단축키로 보던 링크 전송)

## 페이지 2: 로딩 페이지

> **경로:** `/analyzing`
> **목적:** 링크 입력 후 AI가 분석 중임을 단계별 메시지로 보여주는 화면. 단순 스피너가 아니라 "뭔가 똑똑한 분석이 진행 중"이라고 느끼게 한다. (예: 뉴스를 읽고 있어요 → 핵심 이슈를 파악하는 중 → 호재·악재 의견을 비교하는 중 → 섹터 영향 그래프를 그리는 중)

- **F-27** 로딩·분석 진행 상태 화면 ("분석 중...", "아티클 생성 중...", 분석 단계별 메시지)

## 페이지 3: 분석 페이지

> **경로:** `/analysis/[id]`
> **목적:** 뉴스 하나에 대한 AI 분석 결과를 상세히 보여주는 핵심 화면. 뉴스 요약·핵심 키워드, 파급 수혜 섹터 그래프(1차→2차→3차), 섹터 영향도 히트맵(긍정/부정), 좋은 신호(호재)/주의할 신호(우려) 관점 비교를 한 화면에 담는다.

- **F-21** 결과 요약 카드 (뉴스 AI 요약 + 호재/악재)
- **F-14** 영향 근거 한 문장 요약 설명
- **F-03** AI 뉴스 분석 — 핵심 키워드·산업 추출
- **F-16** 섹터 상세 설명 (섹터 소개)
- **F-04** 여러 관점 뉴스 종합·중립 평가
- **F-06** 산업 간 연결·파급 경로 시각화 (산업 연결지도)
- **F-07** 노드 그래프(네트워크형) UI
- **F-08** 1차 → 2차 → 3차 후속 수혜 산업 하이라이트
- **F-11** 다음 수혜 산업 탐색
- **F-13** 노드 연결선 툴팁 — 한 줄 근거 + 근거 출처 뉴스 목록 표시
- **F-33** 노드·히트맵 섹터 hover → 해당 섹터 Top5 종목 전일대비 변동폭(%) 토글 표시
- **F-17** 노드 클릭 → 관련 섹터 상세 보기
- **F-18** 그래프 상 다음 노드 탐색 인터랙션
- **F-32** 섹터 연관도 미리보기 (상세 상단 클릭 시 시각화로 스크롤 이동)
- **F-10** 섹터별 영향도 히트맵 (긍정/부정 색상·크기)
- **F-12** 하락·부정 영향 산업 표시
- **F-05** 뉴스 긍정/부정(호재·악재) 영향 판단
- **F-29** 여론 비율 표시 (호재/동일 N% · 악재/반대 M%)
- **F-30** 호재/악재별 뉴스·증권사 리포트·담당 애널리스트 목록
- **F-22** 비판적 시각(반대 관점) 제공

## 페이지 간 이동 흐름

> 사용자가 페이지를 어떻게 오가는지 순서대로 적는다.

1. **메인(`/`)** 진입 — 상단 입력창에 아티클 링크를 직접 입력하거나(F-01), 크롬 익스텐션(F-20)으로도 바로 진입한다. 메인에서는 인기 뉴스·주요 섹터 현황·최근 분석 내역도 함께 훑는다(F-28).
2. 입력·선택 즉시 **로딩(`/analyzing`)** 으로 이동 — 뉴스 읽기 → 핵심 이슈 파악 → 호재·악재 비교 → 섹터 그래프 생성 단계 메시지를 보여준다(F-27).
3. 분석이 끝나면 **분석(`/analysis/[id]`)** 으로 이동 — 요약·키워드(F-21/F-03), 파급 수혜 그래프(F-06~F-08), 섹터별 영향도 히트맵(F-10/F-12), 호재/우려 여론 비교(F-29/F-30/F-22)를 확인한다.
4. 분석 페이지 안에서 노드·히트맵 섹터에 마우스를 올려 해당 섹터 Top5 종목 전일대비 등락(%)을 확인하고(F-33), 노드·섹터를 클릭해 상세를 탐색하고(F-17/F-18), 상단 미리보기(F-32)로 그래프 위치로 스크롤한다.
5. 다시 **메인**으로 돌아가 다른 뉴스를 분석한다.
