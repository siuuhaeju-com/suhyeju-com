# Step 12. 고객 여정 맵

> 목적: 팀이 **우리 서비스**에서 사용자가 **어떤 순서로 무엇을 하는지** 같은 그림으로 이해한다. (Step 05는 기존·대체 방식, Step 12는 우리 서비스)

> **Guide:**
>
> 1. Agent가 `docs/proposal/11_page_routing_split.md`만 읽고 **고객 여정 맵 초안**을 작성한다.
> 2. 팀이 표를 보며 단계·행동·감정이 맞는지 이야기하고 수정한다.
>
> - **데모에서 보여줄 핵심 여정 1개**를 중심으로 쓴다.
> - Step 11의 **페이지·기능·이동 흐름**을 바탕으로 단계를 구성한다.
> - 각 단계는 **구체적인 행동**으로 쓴다. (예: "앱을 연다" → "일정을 입력하고 추천 버튼을 누른다")
> - Step 05처럼 **표 한 벌**로 정리한다. 팀원 모두가 흐름을 따라갈 수 있어야 한다.

**프롬프트 예시**

```
docs/proposal/11_page_routing_split.md만 읽고 docs/proposal/12_customer_journey_map.md를 채워줘.

규칙:
- Step 11의 페이지 구성·기능 목록·페이지 간 이동 흐름만 참고
- 우리 서비스 기준의 핵심 여정 1개 (데모 가능한 흐름)
- 단계 | 사용자 행동 | 생각/감정 | 해당 페이지 | 사용 기능(F-xx) 표 작성
- Step 11에 있는 페이지와 F-xx를 빠짐없이 연결
- 구조와 상단 Guide는 유지
```

## 여정 요약

> **누가** → **무엇을 하려고** → **어떤 순서로** → **무엇을 얻는다**

- **뉴스를 많이 보는 투자자(주린이 포함)** 가 → **이 뉴스가 어떤 후속 산업까지 번질지 알고 싶어서** → **뉴스 링크 입력 → AI 분석 대기 → 요약·전망 분석·파급 그래프·히트맵·지식그래프 확인** 순으로 → **1차 종목 너머의 다음 수혜 산업과 "왜 그런지" 근거를 얻는다.**

## 고객 여정

> MVP·데모에서 보여줄 주 사용자 흐름

| 단계                     | 사용자 행동                                                                                                                     | 생각/감정                                                                        | 해당 페이지                      | 사용 기능        |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | -------------------------------- | ---------------- |
| 1. 진입·탐색             | 메인에서 상단 링크 입력창 아래의 인기 뉴스·주요 섹터 현황(섹터별 등락률)·최근 분석 내역을 훑어본다                              | "요즘 무슨 이슈가 크지? 뭘 봐야 하지?"                                           | 메인 `/`                         | F-03             |
| 2. 분석 대상 입력        | 관심 뉴스 링크를 입력창에 붙여넣고 분석을 시작한다 (또는 크롬 익스텐션으로 진입)                                                | "관련주 말고, 이 뉴스가 어디까지 영향 가는지 궁금하다"                           | 메인 `/`                         | F-01, F-02, F-11 |
| 3. 분석 대기             | 로딩 화면에서 3D 효과와 함께 "뉴스 읽기 → 키워드 추출 → 전망 분석 → 산업 영향 시각화" 단계 진행을 지켜본다                      | "단순 스피너가 아니네, 뭔가 제대로 분석하는 느낌" (기대·신뢰)                    | 로딩 `/analyzing`                | F-04             |
| 4. 요약·핵심 파악        | 분석 페이지 상단 AI 요약 섹션에서 요약본·핵심 키워드·관련 섹터(변동폭)를 읽고, 필요하면 원문 버튼으로 이동한다                  | "핵심이 한눈에 정리되네, 무슨 섹터 얘긴지 알겠다"                                | 분석 `/analysis/[id]`            | F-05             |
| 5. 전망 분석 비교        | 좋은 신호/주의할 신호 카드를 열어 관련 뉴스·리포트·애널리스트 의견을 비교한다                                                   | "한쪽 말만 듣는 게 아니라 양쪽을 다 보니 판단이 선다"                            | 분석 `/analysis/[id]`            | F-06             |
| 6. 파급 수혜 그래프 탐색 | 1차→2차→3차 파급 노드를 따라가며 다음 수혜 산업을 살핀다                                                                        | "반도체 다음이 전력설비까지 가는구나, 이건 몰랐다" (발견의 재미)                 | 분석 `/analysis/[id]`            | F-07             |
| 7. 노드 깊이 파기        | 연결선 툴팁에서 한 줄 근거와 출처 뉴스 목록을 확인하고, 노드에 마우스를 올려 해당 섹터 Top5 종목 현황(전일대비 %)을 훑는다      | "왜 연결되는지 근거·출처가 있고, 종목 현황까지 바로 보이니 믿음이 간다" (신뢰)   | 분석 `/analysis/[id]`            | F-09, F-10       |
| 8. 긍/부정 조망          | 히트맵으로 이 이슈가 어떤 섹터에 긍정/부정인지 색·크기로 한눈에 보고, 섹터 셀에 마우스를 올려 그 섹터 Top5 종목 현황을 확인한다 | "수혜만 있는 게 아니라 타격받는 섹터도 보이고, 실제 종목 현황까지 바로 확인되네" | 분석 `/analysis/[id]`            | F-08, F-10       |
| 9. 지식그래프 탐색       | 산업 지식그래프를 회전/확대/축소하며 중심 산업과 다른 산업의 연결을 탐색한 뒤, 메인으로 돌아가 다른 뉴스를 분석한다             | "산업 전체가 어떻게 얽혀 있는지 큰 그림이 보이네" (탐색의 재미)                  | 분석 `/analysis/[id]` → 메인 `/` | F-12             |
