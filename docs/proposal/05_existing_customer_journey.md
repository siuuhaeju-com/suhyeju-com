# Step 05. 기존 고객 여정

> 목적: `docs/proposal/04`에서 정의한 서비스 목적을, **지금** 사용자가 어떤 방식으로 달성하는지 정리한다.

> **Guide:** **우리가 만들 서비스의 여정이 아니다.** (우리 서비스 여정은 Step 12 `docs/proposal/12_customer_journey_map.md`) 유사 서비스·대체제·우회 방식마다 **여정을 하나씩** 두고, 단계별 사용자 행동·생각/감정을 표로 정리한다. 각 단계는 상세하게 작성한다. 이 내용을 토대로 Step 06에서 Pain/Wow 인사이트를 추출한다.

## 여정 1

> 증권앱(토스) 요약 + 지인 추천 기반 (근거 없이 반응형)

| 단계           | 사용자 행동                                  | 생각/감정                                        |
| -------------- | -------------------------------------------- | ------------------------------------------------ |
| 종목 선택      | 지인이 추천한 주식을 산다                    | "아는 사람이 추천했으니 일단 믿고 사보자"        |
| 보유           | 사놓고 묵혀둔다                              | 왜 사라고 했는지 근거는 잘 모름                  |
| 변동 발생      | 주가가 오르거나 떨어진다                     | -                                                |
| 알림 수신      | "N% 떨어졌어요 / M% 올랐어요" 알림이 울린다  | 무슨 일이 생겼나 궁금                            |
| 원인 확인      | 토스 앱에 들어가 변동 이유 요약을 읽는다     | "요약의 근거를 더 쉽게 확인하고 싶다"            |
| 매도/보유 판단 | 요약만 읽고 오르길 기다리거나 수익 나면 판다 | 논리적 근거 없이 판단, 초보라 깊은 생각까진 못함 |

## 여정 2

> 뉴스·차트 기반 단타

| 단계      | 사용자 행동                             | 생각/감정                                 |
| --------- | --------------------------------------- | ----------------------------------------- |
| 정보 수집 | 각 뉴스 사이트의 뉴스를 확인한다        | 편향된 뉴스만 확인하게 됨                 |
| 진입      | 뉴스·차트를 기준으로 단타를 친다        | 선동된 주식을 사거나 편향된 정보를 믿음   |
| 지표 해석 | 잘 모르는 차트 지표를 기준으로 매매한다 | "차트 볼 줄도 모르는데.." 기도 메타       |
| 결과      | 결국 마이너스로 끝난다                  | "차트 기반으로 뭔가 제대로 만들면 좋겠다" |

## 여정 3

> 우량주·ETF 적립식 (뉴스와 무관한 장기 매수)

| 단계        | 사용자 행동                                          | 생각/감정                                |
| ----------- | ---------------------------------------------------- | ---------------------------------------- |
| 우량주 선택 | "우리나라 제일 큰 기업은 삼전" → 삼성전자를 산다     | 5만전자, "너무 낮게 평가돼 있다"         |
| 지속 매수   | 뉴스와 관계없이 지속적으로 구매한다                  | 저평가 확신, 초보라 더 깊은 판단은 안 함 |
| ETF 적립    | SPY ETF를 매일 $M씩 산다 (주식 모으기 시작)          | 개별 기업은 무서우니 지수를 모으자       |
| 시장 고민   | "국장이 이만큼 오르네? 국장 할까? 원화가 불안한데.." | 국장/미장 사이에서 갈등                  |
| 종목 탐색   | "ETF 중 오를 만한 게 뭐가 있지?" 찾아본다            | "아직 기업 투자는 무섭다"                |

## 여정 4

> 섹터 추종 (경제 라디오·트렌드 관찰) + AI 추천

| 단계      | 사용자 행동                                                                  | 생각/감정                           |
| --------- | ---------------------------------------------------------------------------- | ----------------------------------- |
| 정보 접함 | 평소 경제 뉴스·라디오를 계속 듣는다                                          | "이런 섹터가 요즘 뜬다는데.."       |
| 흐름 파악 | 잘 팔리는 제품·트렌드를 보고, 돈이 어디에 모이는지 관찰한다                  | "기간이 걸려도 다음 섹터는 이거다!" |
| 종목 추천 | 그 섹터의 종목을 AI에게 추천받는다                                           | 매매 판단에 대한 니즈               |
| 파생 사고 | "이 섹터에 필요한 게 뭐지? 그걸 위해 또 뭐가 필요하지?" 꼬리를 물며 판단한다 | 연결을 따라가며 스스로 생각         |
| 매수      | 폭락 시점에 사거나 주식 모으기를 시작한다                                    | -                                   |

## 여정 5

> 이슈 발생 → GPT·검색으로 수혜주 탐색

| 단계        | 사용자 행동                                                                                             | 생각/감정                                                                                                    |
| ----------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 이슈 인지   | "모 기업이 피지컬AI 투자를 늘린다"는 뉴스를 본다                                                        | 이게 어디에 영향을 줄까?                                                                                     |
| 수혜주 탐색 | GPT에 "피지컬AI 수요가 늘면 어떤 섹터가 수혜주로 오를지" 묻거나, 'XXX 수혜주'로 검색해 관련 글을 읽는다 | 관련 산업을 알고 싶다                                                                                        |
| 후보 확인   | 수혜주 후보를 증권앱에서 확인한다                                                                       | -                                                                                                            |
| 매매        | 뇌피셜로 거래한다                                                                                       | "거래로 이어지든 아니든, 이 섹터가 다른 섹터와 어떻게 영향을 주고받는지 확인하며 '생각'하면서 투자하고 싶다" |

## 여정 6

> 호황기 소문·커뮤니티 추종 (불나방)

| 단계        | 사용자 행동                                                   | 생각/감정                                                  |
| ----------- | ------------------------------------------------------------- | ---------------------------------------------------------- |
| 진입 계기   | 주식 호황기에 "대통령이 코스피 7000 간대!" 같은 소리만 듣는다 | 지금 안 사면 안 될 것 같다                                 |
| 무작정 투입 | 근거 없이 무작정 매수한다                                     | "언제까지 오를까.." 걱정되는 마음                          |
| 이탈        | 불안해서 팔고 나온다                                          | 계속 오를까 초조                                           |
| 후회        | 판 뒤에도 계속 오르자 슬퍼하며 커뮤니티를 보기 시작한다       | "사실 크게 뉴스 보고 들어가는 타입은 아님" — 불나방 스타일 |
