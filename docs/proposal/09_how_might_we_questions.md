# Step 09. "어떻게 하면 ~" 질문 만들기

> 목적: 서비스 방향을 맞춘 뒤, **더 구체적인 생각**으로 수렴한다.

> **Guide:**
>
> 1. Agent가 `docs/proposal/04`, `docs/proposal/06`, `docs/proposal/08`을 읽고 **"어떻게 하면 ~ 할 수 있을까?"** 형태의 질문을 만든다. 직접 질문을 추가해도 좋다.
> 2. 팀이 질문을 보며 답을 이야기한다.
> 3. 각 질문 아래 **답**을 적는다. (타이머 ON)
>
> - 질문은 **많을수록** 좋고, 하고 싶은 말이 많은 질문이 좋다.
> - **실제로 어떻게 할지** 떠올릴 수 있는 질문을 한다. (예: 사용자를 어떻게 모을까? → 너무 넓음)
> - 답은 **질문과 같은 말 반복·뭉뚱그린 표현 금지**. 구체적인 문장으로 쓴다.
>   - (X) 어떻게 하면 사용자가 이 기능을 더 잘 쓸까? → 사용자들이 더 쉽게 쓰게 만들면 될 것 같아요
> - 참고한 서비스·자료가 있으면 답에 적는다.

**프롬프트 예시**

```
docs/proposal/04_service_goal_target_value.md, docs/proposal/06_pain_wow_points.md, docs/proposal/08_word_cloud.md를 읽고
docs/proposal/09_how_might_we_questions.md의 "Agent가 만든 질문" 섹션만 채워줘.

질문 규칙:
- "어떻게 하면 ~ 할 수 있을까?" 형태
- docs/proposal/04 목적·핵심 가치, docs/proposal/06 불편한 점·좋았던 점, docs/proposal/08 키워드를 골고루 반영
- 실제 방법·아이디어가 떠오를 수 있는 질문 (너무 넓은 "사람 모으기"류 X)
- 최소 10개 이상, 서로 겹치지 않게
- 각 질문 아래 답 칸은 비워둬 (팀이 채움)
- "팀이 추가한 질문" 섹션은 건드리지 마
- 구조와 상단 Guide는 유지
```

## 팀이 추가한 질문

> 팀이 논의 중 직접 추가한 질문·논점. 주제별로 정리했다.

### 신뢰성·근거 제공

- 어떻게 하면 뉴스와 산업 연결이 단순 추측처럼 보이지 않고, 왜 연결되는지 근거를 함께 보여줄 수 있을까? 어떤 자료를 함께 제공해야 신뢰성 있는 정보라고 느낄까?
- 어떻게 하면 사용자가 믿을 수 있도록 근거를 보여줄 수 있을까?
- 유사한 과거 뉴스 사례를 함께 제공할까?
- 어떤 근거로 영향을 미치는지 한 문장으로 요약해 설명을 제공할까?

### 연관 산업 판단 — 주체와 기준

- 연관 산업(1차 → 2차 → 3차…)과 산업별 영향도는 누가 판단할 것인가? AI에게 온전히 맡길까, 아니면 판단 기준을 정해 프롬프트로 넣어줄까?
- (참고) 연관 산업 단계 기준
  - **1차 산업** — 뉴스의 영향을 직접 받는 산업. (예: AI 반도체 수요 증가 → 반도체 → GPU → HBM → 파운드리)
    - 판단 기준: 뉴스에 직접 언급됨 / 매출·수요·비용에 바로 영향 / 시장에서 즉시 반응할 가능성 높음
  - **2차 산업** — 1차의 성장·위축 시 공급망·인프라·부품·소재 측면에서 영향받는 산업. (예: → 데이터센터 → 전력설비 → 냉각장치 → 반도체 장비 → 소재)
    - 판단 기준: 1차의 생산·운영에 필요 / 수요가 간접적으로 발생 / 뉴스엔 안 나와도 산업 구조상 연결됨
  - **3차 산업** — 2차의 확장으로 더 넓은 후방·주변 산업에 파급되는 영역. (예: 데이터센터 증가 → 전력망 투자 → 구리 수요 → 변압기 → 전력 인프라 → 부동산/REITs)
    - 판단 기준: 직접 수혜보다 파급 효과 / 시간차 존재 / 근거가 약하면 신뢰도를 낮게 표시해야 함

### 데이터·크롤링·정형화

- 뉴스 크롤링은 어떤 방법으로 할까?
- 어떻게 하면 데이터를 정형화할 수 있을까?
- 어떤 데이터를 쓸까?

### 범위 (섹터·뉴스·구현)

- 재테크 섹터가 많은데 어디까지 다룰까?
- 뉴스의 연결을 어디까지 할까? 어떤 범위까지의 뉴스를 제공해야 할까?
- 구체적인 구현 범위를 어떻게 잡을까?
- MVP에 어떤 section들을 어떻게 배치할까?

### 시각화·UX

- 유저가 자연스럽게 다음 흐름 섹터를 탐색하게 하려면, 섹터연결지도·히트맵 같은 UI/UX를 어떻게 설계할까?
- 시각화 차트는 어떤 식으로 디자인을 잡는 게 좋을까?
- 시각화에 구체적으로 어떤 기술을 활용할까? 그 외 기술 스택은?
- 테마 컬러는 어떻게 선정할까?
- 어떻게 하면 경제를 게임처럼 탐색할 수 있을까?

### 이해 쉽게 (주린이 눈높이)

- 어떻게 하면 복잡한 경제를 3단계만으로 이해시킬 수 있을까?
- 주린이가 이해하기 쉽게, 어떤 방식으로 표현할까?
