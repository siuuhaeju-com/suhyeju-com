# Step 13. 스케치 및 결정

> 목적: 화면 설계안을 **각자 그려본 뒤** 팀이 맞추고, **최종 스케치만** 남긴다.

> **Guide:** (Step 02처럼 **대면 워크숍**으로 진행. Agent가 대신 채우지 않는다.)
>
> 1. **각자** AI(v0, Bolt.new, Cursor 등)에게 `docs/proposal/11`·`docs/proposal/12`을 참고해 **페이지별 화면 스케치**를 그려본다.
> 2. 팀이 스케치를 **공유**하고, 레이아웃·흐름·느낌을 **이야기**한다.
> 3. 합의된 **최종 스케치**만 이 문서에 등록한다.
>
> - 스케치 생성·비교는 각자·팀에서 한다. 이 문서에는 **결정 결과**만 적는다.
> - v0·Bolt.new 등에 넘길 문장은 `docs/proposal/11`·`docs/proposal/12`을 참고해 각자 AI에게 요청하면 된다.
> - 여러 후보 중 **팀이 고른 것**만 적는다. 개인 스케치 전부를 문서에 옮기지 않는다.

## 합의 사항

> 스케치 토론에서 팀이 맞춘 내용

- **디자인 방향:** 다크 테마 + 블루 액센트. "뉴스 한 건이 산업으로 번지는 파장·네트워크"를 배경 파티클과 그래프에 일관 적용해, 데이터가 살아 움직이는 느낌을 준다. 브랜드는 `수혜주.com`.
- **공통 UI 규칙:**
  - 배경은 near-black, 포인트 컬러는 블루(분석하기 버튼·링크).
  - 영향 색상은 **긍정 = 레드(핑크 계열), 부정 = 그린** 으로 통일(섹터 등락·신호 카드·히트맵 공통). 서구와 반대 관례이므로 **범례를 반드시 병기**.
  - 섹터·키워드는 pill(태그) 형태, 등락은 화살표 + % 병기.
  - 카드 기반 2단 레이아웃(콘텐츠 좌 / 요약·현황 우).
  - 좌상단 로고(`수혜주.com`) 고정, 우상단에 '실시간 뉴스 영향력 분석' 상태 표시.
- **구현 시 유의:**
  - 로딩은 단순 스피너 금지 — '뉴스 읽기 → 이슈 추출 → 호재/악재 비교 → 그래프 → 히트맵' 단계 표시로 "똑똑한 분석 중"을 체감시킨다(F-27).
  - 영향력 그래프 연결선 호버 시 한 줄 근거 + 출처 뉴스 목록을 노출(F-13).
  - 파급 그래프·히트맵은 데모 안정성 우선(무거운 3D 연출 과용 주의).
  - 신호 비율(72:28)·애널리스트 코멘트 등 목업 데이터 구조를 실제 스키마와 미리 맞춰둔다.
