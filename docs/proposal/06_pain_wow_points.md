# Step 06. PainPoint / WowPoint

> 목적: `docs/proposal/05` 기존 여정에서 Pain·Wow를 추출하고, 우리 서비스의 개선·차별 방향으로 정리한다.

> **Guide:** 기존 여정에서 사용자가 **불편했던(Pain)** 점은 우리 서비스에서 개선하고, **좋았던(Wow)** 점은 가져와 매력 있고 가치 있는 서비스를 만든다. `docs/proposal/05`의 모든 여정·단계를 검토해 Pain/Wow를 빠짐없이 나열한다.

**프롬프트 예시**

```
docs/proposal/05_existing_customer_journey.md를 읽고 docs/proposal/06_pain_wow_points.md를 채워줘.
각 여정·단계에서 사용자가 불편했던 Pain, 좋았던 Wow를 모두 추출해 나열해줘.
하나로 합치거나 우선순위를 정하지 말고, 발견한 항목을 빠짐없이 bullet로 정리해줘.
구조와 상단 Guide는 유지하고, 본문만 채워줘.
```

## PainPoint

**여정에서 추출 (docs/proposal/05)**

- (여정1·토스) 왜 사라고 했는지 근거를 모른 채, 지인 추천만 믿고 매수한다.
- (여정1·토스) 변동 이유 요약은 있지만, 그 **요약의 근거에 쉽게 접근할 수 없다**.
- (여정1·토스) 요약만 읽고 감으로 매도/보유를 판단한다 — 논리적 근거가 없다.
- (여정2·단타) 편향된 뉴스만 확인해 **선동된 종목**을 산다.
- (여정2·단타) 차트 지표를 모른 채 매매한다("차트 볼 줄도 모르는데"), 기도 메타.
- (여정2·단타) 결국 마이너스로 끝난다.
- (여정3·적립) 개별 기업 투자가 무섭다; 국장/미장·원화 불안 사이에서 갈등한다.
- (여정3·적립) "오를 만한 ETF가 뭐지"를 스스로 판단하지 못한다.
- (여정4·섹터) '뜬다는 소식'과 AI 추천에 의존하는데 **근거·검증이 부족**하다.
- (여정5·GPT/검색) GPT·검색 결과를 뇌피셜로 거래한다; **정보가 여러 곳에 분산**돼 있다.
- (여정5·GPT/검색) 산업 간 영향 관계를 확인하며 '생각'하고 싶지만 마땅한 도구가 없다.
- (여정6·불나방) 소문·헤드라인만 듣고 무작정 진입 → 언제까지 오를지 몰라 불안, 판 뒤 후회.

**팀이 직접 짚은 Pain**

- 상승/하락 요약 정보는 있는데, **구체적으로 왜 연관되는지**는 모르겠다.
- 공격적 종목과, 그게 떨어졌을 때 **보완할 종목**을 모른다.
- 릴스에서 여러 개가 똑같이 추천하는데 **왜 좋은지 모르겠다**.
- 경제 전반을 귓등으로 듣고 투자하거나, 지인 추천으로 결정한다.
- 자신만의 생각 없이 투자해 **시장 변동성에 쉽게 휘둘린다**.
- 이미 잘못된 주관에 갇혀 있다 (예: "무조건 바이오주로 대박", "물 타면 언젠가 오른다").
- 주장하는 **근거가 정확한지 알 수 없다**.
- (Gemini) 정보 과부하와 의사결정 마비 — 데이터는 넘치지만 소화·타이밍 잡기 피로도가 높다.
- (Gemini) 비이성적 뇌동매매 — FOMO·타인 맹신으로 팩트체크 없이 고점 매수한다.
- (Gemini) 수기 기록의 귀찮음 / 손실 시 앱 접속 회피 심리 / AI 의존에 대한 옅은 미심쩍음 / 군중심리 매매 후회.
- (GPT) 투자 가능 금액을 직접 계산해야 함("얼마까지 투자해도 될까?").
- (GPT) 목표가 실행 계획으로 안 바뀜("매달 얼마 넣어야 하지?").
- (GPT) 정보가 너무 많아 헷갈림("뭘 믿지?") / 추천 이유 부족("왜 나한테 맞지?") / 수익률에 감정이 흔들림.

**팀 리서치가 짚은 한계·리스크 (Claude)**

- 근거의 지역 편중 — 강력한 넛지 근거가 미국·유럽 데이터, 한국·동남아·인도에선 미검증(가설).
- '성공'의 정의가 애매 — 참여율·거래량·저축률은 측정했지만 실제 수익·부의 축적은 아님(활동 지표 ≠ 성공).
- 정량 퍼널 없음 — 단계별 전환율·이탈률 벤치마크가 없어 KPI 목표를 세우기 어렵다.
- 후반부(통합·인출/decumulation) 단계 데이터 공백.
- 앱은 예시 수준 — 개별 앱의 사용자수·성과가 미검증이라 경쟁 지형 분석이 얇다.

## WowPoint

**기존 서비스에서 좋았던 점 (감동의 순간)**

- (여정1) 토스가 **변동 이유를 요약**해주는 편리함.
- (여정3) ETF·주식 모으기의 **심리적 안정**(개별 기업의 두려움 회피)과 자동으로 굴러가는 편안함.
- (여정4) 돈이 어디에 모이는지 보며 "다음 섹터"를 **스스로 짚어가는 사고 흐름**과 꼬리를 무는 파생 사고의 재미.
- (여정5) 이슈 → 수혜주까지 GPT로 물어가며 **산업 간 영향을 확인하고 '생각'하며 투자**하고 싶다는 니즈.
- (여정6) 커뮤니티에서 "다 같이 물렸다"는 데서 오는 **묘한 위안·소속감**.
- (Gemini/GPT) 자산을 한눈에 보는 편리함 / 투자 스트레스 없이 본업에 집중하는 안도감 / 하락장 방어의 든든함 / 탑 트레이더 추종의 소속감·짜릿함 / "매번 판단 안 해도 굴러갔으면"(자동투자).
- (Claude) 디폴트·자동증액 넛지의 강력함(저축률 3.5%→13.6%) — 단 '좋은 행동'에 붙일 때; 진입(온보딩) 단계 설계가 승부처(토스 슈퍼앱 가입 3000만).

**우리 제품의 Wow 아이디어 (팀 직접)**

- 유저가 상식적으로 아는 1차 수혜(AI 뉴스 → 반도체)를 넘어, **3·4차 후속 산업을 AI가 짚어 하이라이트**해준다.
- AI가 뉴스의 산업 파급 경로를 **지도로 그려주면**, 개인은 1차 종목 대신 후속 수혜 산업(다음 노드)을 스스로 탐색해 **남보다 먼저 인사이트**를 얻는다.
- 후속 수혜·공급망 정보처럼 **분산된 정보를 자연스럽게 연결하며 가이드**해준다.
- 뉴스 → 산업 → 공급망 → 후속 수혜 기업의 흐름을 **지도처럼** 보여준다(2·3·4차 연결고리 탐색).
- "이걸 위해 뭐가 필요하지?" **연쇄적으로 사고하며 스스로 근거를 찾는 몰입** — 근거 없이 매수하던 경험이 자연스럽게 **공부·성장**으로 이어진다.
- UI에서 **단기 상승 / 장기 상승**을 구분해서 보여준다.
- 상품 가격 - 현물 - 선물 - **상관 관계** 탐색, 글로벌 상품 간 **상관 행렬**(TradingEconomics 레퍼런스).
- 투자자의 **정보 과부하를 해소하고 명확한 인사이트**를 제시한다.
- 기존보다 쉽고 명확하며, 화려한 **시각화에 집중**한다(three.js, gsap).
- (한 문장 요약) 뉴스를 단순 종목 추천으로 끝내지 않고, AI가 산업 파급 경로를 지도처럼 연결해 후속 수혜 산업을 먼저 발견하고 **스스로 투자 근거를 만들게** 돕는다 — 핵심 가치: 정보 과부하 해소, 명확한 근거, 학습·성장.
