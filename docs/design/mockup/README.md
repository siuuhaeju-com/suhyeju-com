# 뉴스 영향력 분석 — 디자인 목업 (구현 참고자료)

수혜주.com **"뉴스 영향력 분석"** 화면의 Claude Design 원본에서 가져온 디자인 소스다.
프런트엔드 구현 시 레이아웃·색·컴포넌트 참고용.

- 원본 프로젝트: **뉴스 영향력 분석 서비스** (소유 ISLAB)
- URL: https://claude.ai/design/p/060e33a1-112f-4e7d-9de4-2a38c9edd900

## 가져온 파일

| 파일                       | 내용                                                                                          |
| -------------------------- | --------------------------------------------------------------------------------------------- |
| `뉴스 영향력 분석.dc.html` | **디자인 소스(마크업)** — 인라인 HTML/CSS. 레이아웃·색·컴포넌트·애니메이션이 그대로 담겨 있음 |
| `support.js`               | Claude Design 캔버스 런타임(`<x-dc>` 템플릿을 React로 렌더). 자동 생성 코드                   |

## 참고 방법

- 코드 참고는 **`뉴스 영향력 분석.dc.html`를 소스로 읽는 것**이 가장 유용하다.
  - 색: 배경 `#0b0d12`, 포인트 블루 `#3d6bff`, 텍스트 `#e9edf4` / 폰트 **Pretendard**
  - 헤더·카드·그래프·히트맵 등 화면 구조와 keyframe 애니메이션이 인라인 스타일로 들어 있음
- 브라우저 렌더는 `<x-dc>` + `support.js`(React 필요) 구조라 단독 실행이 번거롭다.
  **완성된 화면은 claude.ai/design에서 직접 보는 것**을 권장.
