# 이슈 등록 안내

새 이슈가 필요하면 **직접 GitHub에서 만들 필요 없이, 에이전트에게 요청**하면 된다.
Claude·Cursor 등 어떤 AI 에이전트에게든 자연어로 "이런 이슈 등록해줘"라고 말하면,
규칙에 맞게 제목·라벨·본문을 조립해 **자동으로 GitHub에 이슈를 올려준다**(`scripts/new-issue.sh`).

## 어떻게 쓰나

에이전트에게 그냥 말로 요청하면 된다. 예:

> - "메인 페이지에 인기 뉴스 목록 보여주는 **기능** 이슈 등록해줘"
> - "그래프 노드 겹치는 **버그** 이슈 만들어줘"
> - "리드미 오타 고치는 **잡무** 이슈 등록해줘"

그러면 에이전트가:

1. 요청을 보고 **유형(기능 / 버그 / 기타)** 과 제목·라벨을 판단하고
2. 유형에 맞는 **템플릿을 자동으로 골라** 본문을 구성한 뒤
3. **미리보기**로 "이렇게 올릴게요"를 먼저 보여주고
4. 확인하면 **GitHub에 실제 등록** → 이슈 번호·링크를 알려준다.

## 준비 (최초 1회)

이슈를 실제로 올리려면 GitHub CLI 로그인이 되어 있어야 한다.

```bash
gh auth login
```

> Claude Code 세션에서 바로 하려면 프롬프트에 `! gh auth login` 을 입력하면 된다.

## 직접 만들고 싶다면

GitHub 저장소 **Issues → New issue** 에서 템플릿(**✨ 기능 / 🐛 버그 / 🧹 기타**)을 골라
손으로 작성해도 된다. 에이전트가 쓰는 것과 **같은 템플릿**이다.

---

> 제목·라벨 규칙과 본문 템플릿의 실제 정의는 `scripts/new-issue.sh` 와
> `.github/ISSUE_TEMPLATE/` 에 있다. (팀원은 위 방법만 알면 충분)
